## 二、推到 GitHub —— ✅ 已经推完

真实仓库：<https://github.com/XWIDE/comfyui-preset-switch-plus>

```
33edcff  Preset Switch Plus 0.12.19：首个公开版本   ← 我们的
1d0ac88  Initial commit                            ← GitHub 建仓库时生成的（只有 LICENSE）
```

当初的步骤留档（下次换仓库时照做）：

1. 在 GitHub 上新建仓库。**「Repository name」和「Description」是两栏** ——
   第一次就是把名字填成了 `X-WIDE`、把 `comfyui-preset-switch-plus` 填进了描述，
   结果插件里写死的链接全部 404，只能再去 Settings 里改名。
   所以：**名字填 `comfyui-preset-switch-plus`**，描述随便写。
2. 「Add a README」可以不勾。勾了 Add license（GPL-3.0）会生成一个只含
   `LICENSE` 的初始提交，也没关系 —— 我们的 `LICENSE` 跟它逐字节一样，
   `git rebase origin/main` 就能干净地叠上去。
3. 本地：

```bash
git init -b main
git remote add origin https://github.com/XWIDE/comfyui-preset-switch-plus.git
git fetch origin
git rebase origin/main          # 有初始提交时才需要
git push -u origin main
```

> 如果 `git push` 报证书错误（你之前遇到过 `schannel: SEC_E_NO_CREDENTIALS`），
> 可以先执行一次：`git config --global http.sslBackend openssl`，或者改用 GitHub Desktop 上传。
>
> 这台机器上系统级已配好 `credential.helper = manager`（`G:\Program Files\Git\etc\gitconfig`），
> 第一次 push 会弹出标题为 **「Connect to GitHub」** 的窗口，选
> **"Sign in with your browser"** 登录并授权即可，之后 git 会记住凭据。

## 四、进阶：上架 ComfyUI 官方注册表（可选）

上架后，用户在 Manager 里**直接搜名字**就能装，体验最好。

1. 安装发布工具：
   ```bash
   pip install comfy-cli
   ```

2. 登录（会打开浏览器，用 GitHub 账号授权）：
   ```bash
   comfy node login
   ```

3. 在项目目录下发布：
   ```bash
   cd <这个文件夹>
   comfy node publish
   ```

   如果提示 `PublisherId` 不对，按命令行给出的提示把 `pyproject.toml` 里的
   `PublisherId` 改成你的实际 ID 再发一次。

4. 发布成功后，节点会出现在 https://registry.comfy.org ，管理器里可搜到。

> 注意：注册表要求 `pyproject.toml` 里的 `name`、`version`、`PublisherId` 都合法，
> 且每次发布**版本号必须递增**。
