# 发布指南（Preset Switch Plus）

本文件是给你自己看的操作清单，**发布前可以删掉**，也可以留在仓库里。

---

## 一、发布前必改的 3 个占位符 —— ✅ 已填好（v0.12.19）

```toml
authors = [{ name = "X-WIDE" }]
Repository = "https://github.com/XWIDE/comfyui-preset-switch-plus"
requires-python = ">=3.10"
PublisherId = "xwide"
```

- `pyproject.toml` 里的作者、三条 URL、`PublisherId` 都已是真实值。
- `README.md` 安装说明里的两个 URL 也已换成真实仓库地址。
- **唯一还没做的**：仓库本身还没推到 GitHub。推上去之后
  （见第二节），上面这些地址才会真的打得开。

> `PublisherId = "xwide"` 是猜的。真去 `comfy node publish` 的时候，
> 如果命令行说这个 ID 不对，按它给的提示改成你的实际 ID 再发一次。

---

## 二、推到 GitHub

在 GitHub 上新建一个**空仓库**，名字建议：

```
comfyui-preset-switch-plus
```

**不要**勾选 "Add a README"（避免和本地文件冲突）。然后在本地执行：

```bash
cd <这个文件夹>
git init
git add .
git commit -m "Preset Switch Plus 0.2.0: 预设中记录并还原 widget 参数值"
git branch -M main
git remote add origin https://github.com/XWIDE/comfyui-preset-switch-plus.git
git push -u origin main
```

> 如果 `git push` 报证书错误（你之前遇到过 `schannel: SEC_E_NO_CREDENTIALS`），
> 可以先执行一次：`git config --global http.sslBackend openssl`，或者改用 GitHub Desktop 上传。

---

## 三、别人怎么装

推上去之后，任何人用 **ComfyUI Manager → Install via Git URL**，填入：

```
https://github.com/XWIDE/comfyui-preset-switch-plus
```

就能直接装，不用管任何依赖。**这一步做完，你的分享需求就满足了。**

---

## 四、进阶：上架 ComfyUI 官方注册表（可选）

上架后，用户在 Manager 里**直接搜名字**就能装，体验最好。

1. 安装发布工具：
   ```bash
   pip install comfy-cli
   ```

2. 登录（会打开浏览器，用 GitHub 账号授权）：
   ```bash
   comfy node login
   ```

3. 在项目目录下发布：
   ```bash
   cd <这个文件夹>
   comfy node publish
   ```

   如果提示 `PublisherId` 不对，按命令行给出的提示把 `pyproject.toml` 里的
   `PublisherId` 改成你的实际 ID 再发一次。

4. 发布成功后，节点会出现在 https://registry.comfy.org ，管理器里可搜到。

> 注意：注册表要求 `pyproject.toml` 里的 `name`、`version`、`PublisherId` 都合法，
> 且每次发布**版本号必须递增**。
